# Contributing

Issue reports, reproducible benchmark results, research references, and design
discussion are welcome. Include the software versions, environment, exact
inputs, expected output, actual output, and a minimal reproduction where
possible.

The repository currently grants no open-source license and is not yet accepting
outside code contributions. A contributor agreement, DCO policy, governance,
and public license must be adopted before pull requests can be merged. This
protects contributors and preserves the ability to distribute the project
under consistent public and commercial terms.

Do not submit copied, generated, or paper-derived implementation code without
complete source, license, and provenance information.
