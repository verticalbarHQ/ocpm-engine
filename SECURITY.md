# Security policy

Until a private disclosure address is published, do not open a public issue for
a vulnerability that could expose data, bypass tenant boundaries, corrupt
results, or enable code execution. Contact Vertical Bar through its published
company contact channel and request a private security thread.

Supported versions and response targets will be published before the first
generally available open-source release. Benchmark regressions and ordinary
correctness defects may be reported as public issues.
